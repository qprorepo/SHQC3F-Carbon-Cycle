Every numerical value plotted in these figures is logged in
`../results/ALL_NUMERICAL_VALUES.txt` and per-table in `../results/numerics/`.

**Regenerate from your own data** (do not submit figures built on the
synthetic placeholder — check the run log for `[warning] ... synthetic
placeholder`) by editing the file paths in `Config` and re-running:

```bash
python src/shqc3f_co2_figures.py
```
